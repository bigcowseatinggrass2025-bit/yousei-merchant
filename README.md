🎴 專案簡介
「幽街商人」是一款沉浸式東方奇幻風格的桌遊輔助計分系統，以「燈昏巷靜，貨暖人閒」為主題，為您的桌遊體驗提供完整的數位化支援。

✨ 特色功能
🏮 核心遊戲系統
玩家管理：自定義玩家名稱與代表顏色

交易系統：完整的貨物買賣與財富累積機制

護法神獸：五大神獸護法系統，各有獨特能力與覺醒效果

界限突破：神獸真摯認同後的終極力量解放

貨物倉庫：幽街貨物卡片收藏與管理

競猜環節：玩家對賭與寶箱競猜

酒鬼遊戲：問答與骰子挑戰小遊戲

視覺特效：護法降臨動畫、七彩光影效果

隨機背景：多種東方風格背景隨機切換
